# Reuse and attribution

Retain source labels and URLs when reusing the selected metadata. The third-party reports retain their original ownership and terms; the repository does not relicense their full text. This release includes selected metadata and locally authored teaching guidance, not full upstream articles. No blanket license grant has been added; the authors can select licenses for the teaching materials and scripts separately. Cite this repository and the source locators in the data when referring to the artifact.
